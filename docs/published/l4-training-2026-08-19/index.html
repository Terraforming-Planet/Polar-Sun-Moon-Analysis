L4 Training #1 — Findings and Evidence

This was the first 60-minute self-supervised Earth-observation pretraining run. The original page showed only loss and counters; this revision adds the conclusions that can actually be derived from the published evidence, the methodological limits, the provenance gap and the concrete lessons that drove the larger follow-up runs.

What the run actually taught us

These are the strongest conclusions supported by Run #1 without inventing geography, hydrology or climate results that are absent from the public artifact.

FINDING-01DERIVED_VALUE

The optimization pipeline converged on its self-supervised objective

Loss fell from 0.291329 to 0.046198 over the completed one-hour run. That is an 84.14% reduction. The best observed loss was 0.028217, or 90.31% below the initial value.

Supports: CUDA execution, mixed precision, data sampling and the denoising objective worked together for the full run. Does not support: environmental detection accuracy.

FINDING-02DERIVED_VALUE

Run #1 was a narrow-corpus baseline, not a broad Earth survey

The system generated 704,232 sampled training patches from 66 source images — about 10,670 samples per source image on average. The very large samples_seen count therefore represents repeated crops/patches, not hundreds of thousands of independent satellite scenes.

Supports: intensive optimization and pipeline stress-testing. Does not support: calling 704,232 samples 704,232 satellite photographs.

FINDING-03MODEL_ESTIMATE

Generalization remained the main scientific risk after Run #1

Training loss dropped strongly, but no held-out scene-level validation result was published with this run. With only 66 source images, repeated visual structures can be learned very well without proving performance on unseen Earth-observation scenes.

Interpretation: this is a methodological risk assessment, not a measured overfitting percentage. It is why later runs were designed around more unique images, explicit provenance and streaming new windows.

FINDING-04UNKNOWN

No auditable site-level environmental finding can be reconstructed from the public Run #1 artifact alone

The published Run #1 files do not map all 66 inputs to location + acquisition date + sensor + scene identifier + quality flags. Without that manifest, a reader cannot reproducibly say which learned behavior belongs to a specific river, lake, desert, mountain range or country.

Important: this does not prove that the local training files lacked geography; it means the public Run #1 evidence is insufficient to audit environmental conclusions.

Why this page does not claim a river, lake or glacier discovery

Run #1 trained a representation/denoising model. It did not publish deterministic measurements such as water surface area, shoreline displacement, river width, snow/ice fraction, vegetation index, exposed sediment area or cloud-screened before/after scene pairs. Those measurements are required before an environmental finding can be promoted.

Evidence gate: lower training loss is evidence of learning the training objective, not evidence that a lake shrank, a river narrowed, a glacier retreated or a hydrological inlet was blocked.

Design lesson: Run #1 established the compute/training baseline. Run #2 expanded auditable corpus coverage. The next streaming runs must go further by publishing counts of genuinely unique decoded satellite windows and region/year provenance instead of relying on samples_seen.

Do not compare Run #1 and #2 loss values as a model-quality ranking. The input corpora differ, so lower loss on one run can simply mean an easier or narrower reconstruction distribution.

Required outputs for environmental conclusions in future runs

  • Per-scene location, acquisition date, sensor, official source ID and quality/cloud flags.
  • Separate counters for unique decoded satellite windows and repeated optimization samples.
  • Held-out, season-matched scene pairs or time series.
  • Deterministic measurements: water area, shoreline displacement, river width/centerline, snow/ice fraction, vegetation index and exposed sediment where applicable.
  • Region-level results with OBSERVATION / DERIVED_VALUE / MODEL_ESTIMATE / HYPOTHESIS / UNKNOWN labels, uncertainty and provenance.
  • Causal claims only when independent hydrological, geological or meteorological evidence supports them.
