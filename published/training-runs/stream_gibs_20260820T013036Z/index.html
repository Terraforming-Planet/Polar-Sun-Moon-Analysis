L4 Training #3 — Global Streaming Findings and Evidence

Training #3 was the first large-scale streaming run. Instead of repeatedly training only on a small static local corpus, the pipeline continuously requested public NASA GIBS MODIS/VIIRS true-colour imagery from many parts of Earth, decoded each geospatial/time window, moved image batches to CUDA and optimized the model while network workers prepared the next windows. The run stopped after reaching its 200,000-window target, before the full 60-minute time ceiling.

What “200,016 images” really means

The correct scientific wording is 200,016 distinct geospatial/time WMS windows actually decoded and used for optimization. These are not guaranteed to be 200,016 independent satellite source scenes. The same underlying observation can yield multiple requested map windows, and identical rendered content can appear in different requested windows.

The SHA-256 audit found 156,863 distinct payload contents. Therefore 43,153 trained windows had payload bytes identical to at least one other trained window. The content-unique ratio was 78.43%.

Also important: Training #3 did not perform 200,016 × 200,016 pairwise environmental comparisons. It trained on 200,016 requested windows. A real “before vs after” Earth-change comparison requires a separate matched-pair analysis stage with cloud/quality filtering and deterministic measurements.

What the run actually taught us

FINDING-01DERIVED_VALUE

The 200k remote-window target was reached successfully

The system used 200,016 distinct requested geospatial/time windows, reaching 100.008% of the configured 200,000 target. It finished in 54.90 minutes, so the target was reached before the one-hour ceiling.

Supports: scalable concurrent data ingestion + GPU optimization on the live public-source pipeline.

FINDING-02DERIVED_VALUE

Content diversity was high but not identical to request diversity

The 200,016 trained windows produced 156,863 unique SHA-256 payloads. That means 78.43% of trained requests had unique content and 21.57% repeated content already seen elsewhere in the run.

Lesson: future dataset accounting should report both geospatial/time requests and unique payload content.

FINDING-03DERIVED_VALUE

The network/data pipeline was highly reliable during the run

Only 2 recorded fetch failures occurred while 200,016 windows were trained. The recorded failure rate was approximately 0.0010%. About 1.823 GB of remote image payloads were streamed.

Measured throughput: ~60.73 trained remote windows/s.

FINDING-04DERIVED_VALUE

The self-supervised objective improved strongly at global streaming scale

Loss fell from 0.258889 to 0.069581, a 73.12% reduction. The best observed loss was 0.011324, or 95.63% below the initial value.

Supports: optimization remained stable while new data arrived continuously. Does not support: Earth-change detection accuracy.

FINDING-05DERIVED_VALUE

The run achieved genuine geographic breadth

The saved log covers 75 named research regions across lakes, major rivers, deltas, wetlands, glaciers, ice shelves, deserts and control areas. Examples include Lake Kuchnia, Vistula, Grays Harbor, Great Salt Lake, Himalaya/Nepal, Tibetan Plateau, Sahara, Aral Sea, Lake Chad, Amazon, Nile, Mississippi, Greenland glaciers and Antarctica.

Coverage design: each region was sampled across multiple years, seasons and spatial cells rather than represented by a single picture.

FINDING-06UNKNOWN

Environmental change conclusions are still not established by the training log alone

The run did not persist per-window water fraction, shoreline position, snow/ice fraction, vegetation index, exposed sediment, channel width or paired before/after change metrics. Therefore the training report cannot honestly claim “Lake X lost Y hectares” or “Glacier Z retreated N metres.”

Next scientific stage: deterministic pixel analysis on matched seasonal scene/window pairs using the provenance already collected.

Scientific interpretation

Training #3 is a major scaling result for the data-and-training pipeline, not yet a finished Earth-change detector. It demonstrates that the project can continuously stream, decode and train on a very large, globally distributed public NASA GIBS image workload on a Windows NVIDIA L4 environment with very low transport failure. It also demonstrates broad temporal and geographic coverage across 75 research regions. The next scientifically meaningful step is to reuse this provenance structure for matched before/after measurements: cloud-quality filtering, water/snow/vegetation masks, shoreline or channel geometry, uncertainty estimates and evidence classes for every claimed change.

TP-26 evidence policy: OBSERVATION / DERIVED_VALUE / MODEL_ESTIMATE / HYPOTHESIS / UNKNOWN are kept distinct. A training window count is not silently promoted into a unique-scene count or an environmental discovery.
