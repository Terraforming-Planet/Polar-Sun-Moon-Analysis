Earth–Space 512

A scientific 512-cell spatial address model for Earth–Moon–Sun geometry, near-Earth context and observer-direction experiments. The base grid contains exactly 512 top-level cells; it is a reasoning and indexing model, not a claim of 512 physical sensors.
